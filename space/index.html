01 / Herramientas

Distintas fuentes.
Un mismo flujo de trabajo.

Cada procesador aporta evidencias con procedencia. El revisor decide si son suficientes o necesita continuar.

{ }

Código y cálculo

Inspección o ejecución de adjuntos Python y expresiones restringidas para verificar operaciones sin adjunto.

∑

Hojas de cálculo

Planes de agregación deterministas, filtros explícitos y contexto original para revisar los resultados.

▤

Documentos y PDFs

Extracción de texto y selección de fragmentos relevantes, conservando referencias a páginas.

↗

Web y publicaciones

Búsqueda, Wikipedia, seguimiento de enlaces y lectura de papers disponibles en HTML o PDF.

◉

Información visual

Un modelo de visión local examina imágenes y una selección de fotogramas guiada por la pregunta.

▷

Audio y vídeo

Transcripción con marcas de tiempo, clasificación de eventos acústicos y revisión de instantes adicionales.

¿Qué se ejecuta en este Space?

Esta página presenta el proyecto y enlaza a su código. El agente, el panel de evaluación y los modelos se ejecutan en el equipo local siguiendo las instrucciones del repositorio.

¿Cómo se mide la calidad?

Se contrastan las respuestas con la evaluación GAIA del curso y se revisan fuentes, fallos y latencia. El proyecto está en desarrollo; esta página no declara certificación ni una puntuación garantizada.

¿Dónde puedo reproducirlo?

El código incluye la configuración del entorno con uv, el lockfile, las pruebas y los lanzadores. Consulta la guía de ejecución local ↗. El acceso a GAIA requiere autorización del dataset.

¿Qué queda por mejorar?

La precisión de los modelos, el equilibrio entre razonamiento y latencia y la cobertura de las evidencias siguen siendo áreas de trabajo. El muestreo parcial de vídeo y la extracción de PDFs tienen límites documentados.
